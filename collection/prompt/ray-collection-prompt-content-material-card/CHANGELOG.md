### README 修订（Codex 合并修订项）

- **O 的定义收紧**：O 限定为「发布方自己的正式渠道」（官方文档、平台公告、规则页、原始数据）。
  去掉原「原作者原文」作为 O 的情形——**博主个人观点／经历即使能逐字回读，仍按 E**。
  补入「能不能回读 ≠ 观点是否为真」，并说明可回读**不自动授予引用或再分发许可**。
  给出官方公告与博主原文各一例对照。
- **「无」与「待补」中英统一**：确认未发生／不适用写「无」，缺失／无法取得／不确定写「待补」。
  强调**不要用「无」掩盖「不知道」**。
- **可选字段与「不得留空」的冲突已划清**：可选字段允许省略或空值；「没有整段留空」
  针对九节正文与必填身份字段。两者不再互相抵触。
- **正文保真范围明确**：第六节正文全文必须原文／原转写；**第二节「内容总结」允许概括**，那是它的用途。
