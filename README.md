## 目录结构

```
collection/<类型>/<规范名>/
├── README.md          该资产的完整说明（用途/输入输出/依赖/限制）
├── LICENSE            该资产的许可全文
├── NOTICE.md          权属、来源与改动说明
├── CHANGELOG.md       该资产的版本变更
├── MANIFEST.txt       逐文件完整 SHA256，可校验下载完整性
└── templates/         资产的主要文件
```

---

## 怎么用

1. 进你要用的资产目录，先读它的 `README.md`
2. 按 `MANIFEST.txt` 校验完整性（可选，但推荐）
3. 按 `LICENSE` 确认你能做什么

**各资产的许可不同，请以该资产目录内的 `LICENSE` 为准，不要套用其他资产的许可。**

---

## 校验下载完整性

每个资产目录都有 `MANIFEST.txt`，含逐文件完整 SHA256。下载后校验：

```bash
cd <资产目录>
awk 'NR>5{print $1"  "$3}' MANIFEST.txt | shasum -a 256 -c
```

全部显示 `OK` 即文件未被改动。
